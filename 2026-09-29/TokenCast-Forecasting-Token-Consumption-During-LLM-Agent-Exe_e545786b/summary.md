# 论文速读：TokenCast-Forecasting-Token-Consumption-During-LLM-Agent-Exe

## 一句话总结
TokenCast 提出了一种基于可组合代价表示的 LLM Agent 执行过程中 Token 消耗在线预测方法，通过将执行轨迹分段并显式建模上下文累积带来的重复输入成本，在无需额外 LLM 调用、平均仅需 32.8 ms 延迟的情况下，相比最强基线将 MAE 平均降低 14.5%，并在离线预算控制回放中节省 21.3% 的 Token。

## 研究问题与动机
1. **核心问题**：LLM Agent 执行相同任务时，因工具反馈、中间结果和上下文累积，跨运行 Token 消耗差异可达 30 倍，难以在运行前或运行中准确预测总成本。
2. **单请求级方法局限**：TRAIL、EGTP、TIE 等仅针对单次模型调用的响应长度预测，依赖已知 prompt 或模型内部中间状态，无法处理 Agent 任务中后续请求在前期动作完成前不存在、且输入成本受历史累积影响的耦合问题。
3. **任务级预执行估计局限**：Self-Prediction 等方法仅在任务开始前让模型自我评估估算总消耗，缺乏对执行过程中上下文增长与后续调用成本耦合关系的建模，且会引入额外 LLM 调用开销。
4. **动机**：需要一种能够利用已观测执行证据实时更新预测、显式刻画“早期段落的上下文增长会导致后期所有调用输入膨胀”这一机制的轻量级预测器，从而支持动态预算控制与资源调度。

## 核心贡献（创新点）
1. **提出分段代价因子化与精确组合恒等式**：将连续调用块表示为三元组 `(n, g, b)`，并通过恒等式 `φ_{A∘B} = (n_A+n_B, g_A+g_B, b_A+b_B+n_B·g_A)` 精确分离基线输入成本、增量残差与上下文累积的交叉项。
2. **设计分阶段前缀-后缀预测器**：将剩余成本预测分解为前缀段表示、边界状态与后缀段表示三部分，结合直接预测路径与组合预测路径，利用已完成的执行证据实时更新，全程无需额外 LLM 调用。
3. **引入跨折叠训练与代价加权损失**：针对 `g` 和 `n` 的预测误差会通过组合恒等式级联放大至下游成本，设计权重损失 `ℓ_g = n_B·|ĝ_A - g_A|` 与 `ℓ_n = L_B·|n̂_B - n_B|`，并采用 cross-fitting 缓解前缀预测误差对后缀模型训练的分布偏移。
4. **全面的基准验证与预算控制应用**：在 4 个基准、6 个 Agent LLM、96 种组合下取得最优平均性能；在 SWE-bench Verified 离线回放中实现与固定预算相同的轨迹完成率前提下节省 21.3% 的 Token。

## 方法详解
- **四个预测时机**：Task Start（执行前预测总消耗 T）、Call Start（当前请求组装完成后预测本次消耗 C_k）、In-call Update（生成中根据已输出前缀更新 C_k）、Task Update（每次调用完成后更新剩余消耗 R_k，得 T̂_k = S_k + R̂_k）。
- **段表示与组合恒等式**：段落 A 从输入长度 L_A 开始，包含 n_A 次调用，净输入变化 g_A，总消耗 C_A。残差 b_A = C_A - n_A·L_A。相邻段落 B 从 L_B = L_A + g_A 开始，组合后第三维多出交叉项 `n_B·g_A`，该项精确对应“前一段落引入的上下文增量在后续 n_B 次调用中被重复计入输入成本”的物理含义。
- **预测器架构**：底层统一使用 LightGBM。任务级预测包含两条路径：直接路径将剩余总消耗作为单一目标回归；组合路径分别预测前缀段 `(n̂_A, ĝ_A, b̂_A)`、边界状态与后缀段，再通过恒等式合成剩余消耗。最终通过一个修正模型（correction model）融合两条路径的预测值、残差与边界变量输出结果。
- **训练策略**：局部绝对损失对 `g` 和 `n` 施加 `n_B` 和 `L_B` 加权以抑制级联误差；后缀模型训练时使用跨折叠（cross-fitting）产生的前缀预测边界，并重新计算后缀残差标签 `b_B^{train} = C_B - n_B·L̂_B`；校准阶段使用保留集训练独立的 0.05/0.95 分位数 LightGBM 模型，并对原始区间进行对称加宽以满足目标覆盖率。
- **在线更新机制**：每次调用完成或生成前缀达到检查点（每 128 UTF-8 字节）时触发重预测，特征严格限制为当前预测点可见的执行记录，推理时间极低（SWE-bench Verified 上平均每调用更新累计 32.8 ms）。

## 实验与结果
- **数据集与基线**：4 个基准（SWE-bench Verified, Search-R1, MMLU-Pro, LongBench-v2），6 个 Agent LLM（GPT-5.4, Claude Opus 4.6, Gemini 3.1 Pro, DeepSeek-V4-Pro, Qwen3.8-27B, Llama-3.2-3B-Instruct），共 11,712 条执行轨迹。
