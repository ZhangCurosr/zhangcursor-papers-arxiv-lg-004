# 论文速读：Teacher-Student-Gaps-Are-Not-Enough-Outcome-Guided-On-Policy

## 一句话总结
论文揭示了多轮自主智能体蒸馏中存在的“监督–收益错配”现象，并据此提出了结果引导的在线策略蒸馏（OG-OPD）框架。该方法通过轨迹相对加权定位候选干预轮次，并借助成对学生延续轨迹的最终任务结果来校准教师监督强度，从而在多轮场景下实现对当前学生真正有益的针对性指导。

## 研究问题与动机
- **核心问题**：现有面向多轮自主智能体的在线策略蒸馏（OPD）方法，常将较大的教师–学生token级分布差距视为强干预信号，但该做法未能有效区分“监督是否真正有利于当前学生完成最终任务”。
- **现有不足一**：仅依赖局部差距定位干预点，忽视了多轮交互中的**链式效应**——当前轮次的动作会影响后续状态序列与决策机会，局部差距大并不代表该轮次的教师指导具有正向收益。
- **现有不足二**：部分方法（如FutureBridge-OPD）将教师偏好的响应直接作为额外蒸馏目标，未从**当前学生自身后续执行能力**的角度验证教师指导的实际价值。
- **现有不足三**：缺乏对“教师指导可能有害”的系统性度量与规避机制，实证显示在大差距决策中教师有害比例（10.8%）甚至超过教师救助比例（8.8%）。

## 核心贡献（创新点）
1. **发现并量化了监督–收益错配现象**：通过ScienceWorld与WebShop上的配对实验，实证表明大差距可能无害甚至有害，而小差距可能决定成败，揭示了仅凭局部差距无法判断指导收益的根本缺陷。
2. **提出了OG-OPD框架**：将轨迹相对加权（trajectory-relative weighting）、基于差距增量的候选轮次选择与基于最终任务结果的校准（outcome-based calibration）三者结合，实现了对“当前学生能转化并获益”的监督信号的精准强化。
3. **与已有工作的本质区别**：不同于FutureBridge-OPD等直接将教师响应加入蒸馏目标的方法，OG-OPD仅在原学生轨迹上基于成对执行结果**选择性强化**监督权重，教师响应仅用于校准而不作为额外训练目标，避免了对非当前学生能力范围内的指导信号进行盲目学习。
4. **广泛的实验验证**：在ALFWorld、ScienceWorld、WebShop三个具有代表性的多轮智能体基准上，使用不同规模的教师–学生配置（Qwen3-32B/1.7B 与 Qwen3-8B-RL/4B），均实现了最高的任务成功率，显著优于vanilla OPD及多种最新基线。

## 方法详解
OG-OPD在标准OPD的reverse KL目标基础上，对每个轮次的监督损失施加可校准的权重，核心分为三步：

1. **轨迹相对加权（Trajectory-Relative Weighting）**：
   - 定义第k轮的token级差距幅度 $\chi_k = \frac{1}{|\mathcal{M}_k(\zeta)|} \sum_{j \in \mathcal{M}_k(\zeta)} |\psi_{k,j}|$，其中 $\psi_{k,j}$ 为教师与学生token概率的对数比。
   - 以轨迹中首个有效轮次 $k_0$ 的差距为参考，计算对数差距 $\nu_k = \log(\varepsilon_0 + \chi_k)$，以及相邻轮次变化量 $v_k = \nu_k - \nu_{k-1}$。
   - 预校准权重 $\beta_k$ 按 $\exp(\nu_{k_0} - \nu_k)$ 进行轨迹内归一化，防止差距过大的轮次获得过高监督系数，同时上限为 $\beta_{\max}$。

2. **候选轮次选择（Candidate Selection）**：
   - 仅当轮次满足：差距对数值 $\nu_k \geq \vartheta_\nu$，且（若是初始轮则豁免；否则要求正变化量 $v_k > 0$ 且 $v_k \geq \vartheta_v$）时，才进入候选集。
   - 阈值 $\vartheta_\nu, \vartheta_v$ 取批次内各轨迹贡献相等的分位数。
   - 在预算限制内，按时间顺序检查候选轮次，选取第一个教师响应可解析出**与学生原始动作不同**的合法动作的轮次进行下一步验证。

3. **基于结果的校准（Outcome-Based Calibration）**：
   - 在选定的候选轮次 $k^*$，从该轮次状态和历史出发，分别以**学生原始响应** $z_{k^*}^S$ 和**教师响应** $z_{k^*}^T$ 为起点，使用**相同的冻结当前学生策略** $p_\circ$、相同的解码设置与种子继续执行，得到两条配对延续轨迹 $\tilde{\zeta}^S$ 与 $\tilde{\zeta}^T$。
   - 计算最终任务结果差异 $\Delta_\zeta = S(\tilde{\zeta}^T) - S(\tilde{\zeta}^S) \in \{-1,0,1\}$。
   - 仅当 $\Delta_\zeta = 1$（即学生原始动作失败但教师动作带来成功）时，才认为该轮次的教师指导对当前学生有益，产生校准增益 $g_\zeta = 1$；否则 $g_\zeta = 0$。
   - 最终校准权重 $\omega_k$ 在候选轮次 $k^*=k$ 时增加增量 $\gamma_\zeta = g_\zeta [\beta_\uparrow - \beta_k]_+$（$\beta_\uparrow$ 为结果增强的权重下限），其余轮次保持 $\beta_k$ 不变。
   - 训练目标仍为原学生的token损失加权和，教师响应及配对轨迹本身不作为额外的蒸馏目标：
     $$\mathcal{L}_{\text{OG-OPD}}(\theta) = \frac{1}{Z} \sum_{\zeta} \sum_{k} \text{sg}[\omega_k] Q_k(\theta;\zeta)$$

## 实验与结果
- **数据集与模型**：ALFWorld、ScienceWorld、WebShop；主实验使用 Qwen3-32B 教师与 Qwen3-1.7B 学生；补充实验使用经GiGPO训练的 Qwen3-8B-RL 教师与 Qwen3-4B 学生。
- **评估基线**：Vanilla OPD、TCOD-F2B、TCOD-B2F、Guided-OPD、FutureBridge-OPD，以及零样本师生。
- **主要结果**：
  - **ALFWorld** (Qwen3-32B→1.7B)：OG-OPD Overall SR 为 **24.2%**，对比 Vanilla OPD 的 20.1% 提升 4.1pp；在Qwen3-8B-RL→4B设定下达到 64.2%，超越最强基线 FutureBridge-OPD (62.7%)。
  - **ScienceWorld** (Qwen3-32B→1.7B)：OG-OPD SR 为 **16.6%** (Score 52.0)，对比 Vanilla OPD (13.0%) 提升 3.6pp。
  - **WebShop** (Qwen3-32B→1.7B)：OG-OPD SR 达到 **45.7%** (Score 44.3)，对比 Vanilla OPD (28.0%) 提升 **17.7pp**，对比最强基线 FutureBridge-OPD (38.7%) 提升 **7.0pp**。
  - OG-OPD在多数设置下还实现了更短的交互回合数。
- **训练动态**：在WebShop上，OG-OPD的教师似然度与动作可解析率恢复更早；额外增加的加权轮次占比不足1%，但带来了显著的性能提升。
- **训练成本**：每步训练成本约为Vanilla OPD的1.42×(ScienceWorld) 与 1.48×(WebShop)。

## 相关工作脉络
1. **TCOD (Wang et al., 2026)**：通过时序课程扩展学生 rollout 深度或缩短教师成功轨迹前缀。本文与其在“如何组织多轮监督”的目标上一致，但 TCOD 缺乏对单个干预点是否真正利于当前学生完成最终任务的验证机制。
2. **Guided-OPD (Li et al., 2026)**：在轨迹内交错师生轮次并逐渐减少教师干预概率。本文同样关注轮次级指导，但 Guided-OPD 依赖概率调度，而 OG-OPD 基于结果反馈对特定轮次进行确定性强化。
3. **FutureBridge-OPD (Chen et al., 2026)**：同样利用大差距定位干预点，但使用**教师偏好 token 在配对延续中的比例增长**作为验证信号，并将接受的教师响应作为**额外的蒸馏目标**。本文的核心差异在于：验证信号改为**当前学生在两种动作下的最终任务结果**，且仅强化原学生轨迹的权重，不引入新目标。
4. **传统 OPD (Agarwal et al., 2024)**：在固定分布上最小化 reverse KL。本文继承了“在学生学习轨迹上提供密集监督”的核心思想，但通过轨迹相对加权与结果校准解决了多轮场景下的监督信号失真问题。
5. **序列级蒸馏 (Ranzato et al., 2016; Bengio et al., 2015)**：早期工作关注训练-推理分布失配。本文在思想延续上进一步引入了“最终任务结果”作为分布校准的收益衡量标准。

## 局限性与未来方向
- **局限性**：
  1. 每步训练需额外执行配对学生延续轨迹，带来约40%-50%的计算开销。
  2. 结果校准高度依赖**任务最终二值成功信号**，对于具有中间奖励或过程性反馈的环境（如连续控制、长程规划）可能不够精细。
  3. 当前验证仅在三个具身智能/网页交互基准上进行，尚未在更复杂的开放式多轮对话或代码生成等长轨迹场景充分验证。
  4. 配对执行依赖相同的冻结学生策略，若策略在延续过程中方差较大，单次采样的结果对比可能不稳定。
- **未来方向**：
  1. 将结果校准信号推广至**稀疏奖励或过程奖励**设置，设计细粒度的阶段性收益估计。
  2. 探索**更高效的配对执行策略**（如并行化、采样优化）以降低额外计算成本。
  3. 结合**值函数近似**或**预测模型**来低成本地估计“采取教师动作后的预期任务价值”，替代完全的执行对比。
  4. 将框架扩展至**多模态或工具调用**环境，验证其在更复杂交互结构下的通用性。

## 研究启发与可借鉴点
1. **“结果导向”的监督校准思想**：在多步决策或规划场景中，干预信号的有效性不应仅由当前状态的局部差异判断，而应通过**模拟后续执行并观察最终收益**来验证。这一思想可迁移至强化学习中的价值函数设计、多阶段知识蒸馏、或任何涉及长期影响的干预选择问题。
2. **配对连续执行的验证范式**：采用相同的冻结策略、相同的随机种子和相同的剩余预算，仅改变一个动作/响应进行对比执行，是一种干净且可复现的“干预效果评估”方法。可用于任何需要量化单一决策点影响大小的研究。
3. **轨迹内相对归一化**：使用轨迹内首个有效轮次作为参考点，对差距幅度进行指数归一化，可以有效缓解不同任务长度、不同难度轨迹间的监督强度不可比问题。该技巧可应用于任何基于差距或重要性比值的加权场景。
4. **轻量级验证预算控制**：通过分位数阈值筛选候选轮次、仅对“第一个验证有效的轮次”进行昂贵的配对执行，以极小的额外计算成本（<1%的轮次获得加权）获得了显著的性能提升。这一“稀疏强化”策略值得在资源敏感的多步学习系统中借鉴。

## 关键术语表
- **On-policy Distillation (OPD)**：在智能体自身产生的轨迹数据上，利用教师模型的密集 token 级概率反馈对其进行蒸馏的训练范式。
- **Supervision-Benefit Mismatch**：指教师–学生局部差距大（暗示需要强监督）的轮次，其教师指导未必能带来最终任务收益提升，甚至可能有害的现象。
- **Trajectory-Relative Weighting**：以轨迹内首个有效轮次为基准，通过对数差距差值的指数缩放，在不同轮次间归一化教师监督强度的加权机制。
- **Paired Student Continuations**：从同一历史状态出发，分别采用学生原始响应和教师响应作为下一步，在相同冻结学生策略下继续执行直至终止，得到两条可比较的后续轨迹。
- **Outcome-Based Calibration**：仅当配对执行结果显示“教师动作挽救了学生原本的失败”时，才对该轮次的学生原始响应损失施加额外的监督权重。
- **Teacher Rescue / Teacher Harm**：分别指配对执行中教师动作带来成功而学生原动作失败、以及教师动作导致失败而学生原动作成功的情形。
- **Agent On-Policy Distillation**：将OPD应用于多轮自主智能体场景，重点解决交互过程中分布漂移、错误累积和长程依赖的蒸馏问题。

## 可复现要素
- **数据集**：ALFWorld、ScienceWorld、WebShop，均为公开基准，论文已提供实验配置细节。
- **代码/权重**：论文声明“提供源代码在附录材料中”（We provide the source code in the supplementary material accompanying this submission）。教师模型使用 Qwen3-32B 及 GiGPO 训练的 Qwen3-8B-RL。
- **关键超参数**：
  - 预校准权重上限 $\beta_{\max} = 1.2$
  - 结果增强权重下限 $\beta_\uparrow = 1.5$
  - 差距幅度分位数阈值 $q_\nu = 0.5$，正变化分位数阈值 $q_v = 0.6$
  - 每轨迹最多检查 2 个候选、最多 1 个配对执行位置
  - 训练步骤 200，每 seed 3 次
- **硬件**：8×A800 GPU。
